TUTORIAL RANN CODE
==================

Untuk pengguna baru, dari nol sampai bisa dipakai.
Tidak perlu sudah punya file Rann Code di laptop.
Cukup pasang sekali, lalu pakai perintah rann.
Tidak perlu pnpm.
Tidak perlu Git.

Versi tutorial: 1.3
Versi Rann Code: 1.1.0
Diperbarui: 7 November 2026
Sistem: Windows 10/11, macOS, dan Linux
Syarat utama: Node.js 22 LTS

Dokumen ini bisa dibagikan ke siapa saja. Semua langkah ditulis untuk orang
yang baru pertama kali memakai terminal.


0. APA YANG AKAN KAMU PASANG
===========================

Rann Code adalah aplikasi terminal untuk mengobrol dengan AI coding agent.
Agent bisa membaca file, menulis file, menjalankan perintah, menyimpan memori,
dan membuat skill.

Ada dua bagian yang perlu dipasang:

1. Node.js
   Mesin yang menjalankan aplikasi. Ini yang kamu unduh dari nodejs.org.

2. Rann Code
   Aplikasi yang dipasang lewat satu perintah npm. File aplikasinya diambil
   dari URL rilis, jadi kamu tidak perlu punya source code atau folder
   khusus di komputer.

Setelah terpasang, perintah yang dipakai adalah:

    rann

Rann Code menyimpan data di laptop sendiri. Prompt hanya dikirim ke provider
model yang kamu pilih. Kalau memakai provider mock, tidak ada koneksi ke model
sama sekali.


1. SIAPKAN WAKTU DAN INTERNET
============================

Yang dibutuhkan:

- Laptop atau PC.
- Koneksi internet untuk memasang Node.js dan Rann Code.
- Terminal:
  - Windows: Command Prompt atau PowerShell.
  - macOS: Terminal.
  - Linux: Terminal.

Tidak perlu kartu kredit untuk mencoba alur aplikasi dengan provider mock.
Kalau ingin jawaban AI sungguhan, kamu perlu API key dari provider model.

1.1 Cara membaca tutorial ini

Baris yang menjorok ke kanan adalah perintah. Contoh:

    node -v

Cara memakainya:

1. Blok perintah dengan mouse.
2. Salin dengan Ctrl+C, atau Command+C di macOS.
3. Tempel di terminal dengan Ctrl+V, atau Command+V di macOS.
4. Tekan Enter.

Jangan menyalin tanda `$` atau `>` kalau tanda itu muncul di contoh. Tanda
tersebut hanya penanda terminal, bukan bagian perintah.

Kalau sebuah perintah panjang terpotong menjadi beberapa baris dalam tutorial,
salin semuanya sebagai satu baris. Jangan menekan Enter di tengah perintah.


2. PASANG NODE.JS
=================

Rann Code membutuhkan Node.js versi 22.11 atau lebih baru. Tutorial ini memakai
Node.js 22 LTS. Node.js 24 LTS juga memenuhi syarat, tetapi kalau modul database
gagal dipasang, kembali ke Node.js 22 LTS.

2.1 Windows 10 atau 11

1. Buka https://nodejs.org
2. Unduh versi LTS untuk Windows.
3. Jalankan file .msi.
4. Klik Next sampai selesai. Biarkan opsi "Add to PATH" tercentang.
5. Tutup semua Command Prompt yang lama.
6. Buka Command Prompt baru:

   Tekan tombol Windows, ketik cmd, lalu Enter.

7. Cek:

    node -v
    npm -v

Contoh hasil yang benar:

    v22.23.3
    10.9.4

Nomor versi Node minimal 22.11. Nomor npm tidak harus sama.

Di Windows, tool shell memerlukan `bash`. Pasang WSL 2 atau jalankan Rann Code
dari Git Bash. Tanpa `bash`, baca dan tulis file tetap berjalan, tetapi perintah
shell akan gagal.

2.2 macOS

Cara paling mudah:

1. Buka https://nodejs.org
2. Unduh installer LTS untuk macOS.
3. Jalankan installer.
4. Buka Terminal.
5. Cek:

    node -v
    npm -v

Kalau memakai Homebrew:

    brew install node@22

2.3 Linux Ubuntu atau Debian

Buka Terminal, lalu:

    sudo apt update
    sudo apt install -y curl
    curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
    sudo apt install -y nodejs

Cek:

    node -v
    npm -v

2.4 Kalau node atau npm tidak dikenali

Artinya Node belum terpasang atau PATH belum terbaca.

- Tutup terminal, buka lagi.
- Di Windows, pastikan opsi "Add to PATH" dicentang saat memasang.
- Jalankan `node -v` lagi.

Jangan lanjut sebelum `node -v` menampilkan versi 22.11 atau lebih baru.


3. PASANG RANN CODE
===================

3.1 Satu perintah install

Buka terminal, lalu jalankan:

    npm install -g https://github.com/RannD101/rann-code/releases/download/v1.1.0/rann-code-1.1.0.tgz

Arti perintah:

- `npm install`: memasang paket Node.
- `-g`: memasang secara global, supaya perintah `rann` bisa dipakai dari
  folder mana pun.
- URL: lokasi file rilis Rann Code.

Repo publik dan tutorial: https://github.com/RannD101/rann-code

Tunggu sampai muncul pesan seperti:

    added 41 packages

3.2 Cek hasil

    rann --version

Hasil yang benar:

    rann-code 1.1.0

Coba juga:

    rann --help

Kalau dua perintah itu berjalan, Rann Code sudah terpasang. Kamu belum perlu
folder proyek dan belum perlu API key.

3.3 Kenapa memakai npm install -g

`npm install -g` memasang perintah `rann` secara permanen. Versi yang dipakai
selalu sama, dan aplikasi tidak diunduh ulang setiap kali dijalankan.

Jadi pengguna cukup menjalankan `rann`, bukan menjalankan paket sementara
setiap kali ingin memakai agent.

3.4 Kalau muncul error EACCES di macOS atau Linux

Jangan memakai sudo untuk memasang paket npm. Buat folder global sendiri:

    mkdir -p ~/.npm-global
    npm config set prefix ~/.npm-global

Tambahkan ke shell:

    echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
    source ~/.zshrc

Kalau memakai bash, ganti `.zshrc` dengan `.bashrc`.

Ulangi:

    npm install -g https://github.com/RannD101/rann-code/releases/download/v1.1.0/rann-code-1.1.0.tgz
    rann --version

3.5 Kalau `rann` tidak dikenali setelah install

Cek lokasi folder global npm:

    npm config get prefix

Di Windows biasanya:

    C:\Users\NAMA_KAMU\AppData\Roaming\npm

Di macOS atau Linux biasanya:

    /usr/local/bin

Tutup terminal, buka lagi, lalu coba `rann --version`.

Kalau masih gagal di Windows, tambahkan folder `%APPDATA%\npm` ke PATH lewat
Environment Variables, lalu buka Command Prompt baru.


4. PERTAMA KALI MENJALANKAN
===========================

4.1 Buat folder latihan

Di Windows Command Prompt:

    cd %USERPROFILE%
    mkdir rann-projek
    cd rann-projek

Di Windows PowerShell:

    cd $env:USERPROFILE
    mkdir rann-projek
    cd rann-projek

Di macOS atau Linux:

    mkdir -p ~/rann-projek
    cd ~/rann-projek

Folder ini akan menjadi tempat agent bekerja. Jangan jalankan agent di folder
sistem seperti C:\Windows atau /.

4.2 Cek kesehatan instalasi

    rann doctor

Beberapa baris mungkin berstatus warning karena daemon belum jalan dan database
belum dibuat. Itu normal pada pemakaian pertama.

4.3 Coba provider mock

Provider default adalah mock. Mock tidak menghubungi internet dan tidak
menghabiskan token. Balasannya hanya untuk menguji alur.

    rann "halo, jelaskan folder ini"

Atau buat sesi dengan judul:

    rann new --title "Latihan pertama"
    rann "sebutkan isi folder ini"

4.4 Buka chat

    rann chat

Atau cukup:

    rann

`rann` tanpa argumen membuka chat kalau dijalankan di terminal. Kalau dipakai
dari pipe atau cron, ia mencetak bantuan supaya tidak menggantung.

Di dalam chat, coba:

    /help
    /status
    /tools
    /exit

4.5 Arti mock

Mock berguna untuk memastikan instalasi berhasil. Mock bukan model AI
sungguhan. Untuk membaca kode, menulis file, dan menjawab pertanyaan proyek,
kamu perlu provider model di bagian 5.


5. PASANG PROVIDER MODEL
========================

Rann Code adalah agent, bukan model. Ia perlu endpoint model yang kompatibel
dengan OpenAI Chat Completions.

Kamu punya tiga pilihan:

1. OpenAI atau provider berbayar lain.
2. OpenRouter, satu key untuk banyak model.
3. Endpoint dari pengajar, kantor, atau server sendiri.

Kalau hanya ingin mencoba perintah dan izin tool, lewati bagian ini dan tetap
pakai mock.

5.1 Simpan API key di environment variable

Key tidak ditulis ke config Rann Code. Config hanya menyimpan nama variabel.

Windows Command Prompt:

    setx OPENAI_API_KEY "sk-isi-key-kamu"

Setelah `setx`, tutup terminal dan buka lagi. `setx` tidak mengubah terminal
yang sedang berjalan.

Windows PowerShell:

    setx OPENAI_API_KEY "sk-isi-key-kamu"

Di PowerShell, `export` bukan perintah. Untuk satu sesi saja, tanpa menutup
terminal:

    $env:OPENAI_API_KEY = "sk-isi-key-kamu"

macOS atau Linux:

    export OPENAI_API_KEY="sk-isi-key-kamu"

Kalau ingin permanen di macOS dengan zsh:

    echo 'export OPENAI_API_KEY="sk-isi-key-kamu"' >> ~/.zshrc
    source ~/.zshrc

Jangan mengirim API key ke orang lain, jangan menaruhnya di screenshot, dan
jangan memasukkan key ke file proyek.

Jangan memakai `--key` untuk menulis key langsung di perintah. Flag itu tidak
dipakai; Rann Code hanya membaca key dari environment yang disebut lewat
`--key-env`. Kalau key sudah telanjur ditempel di terminal atau chat, buat key
baru di penyedia model dan hapus key lama.

5.2 Daftarkan provider OpenAI

    rann provider add openai --type openai-compatible --base-url https://api.openai.com/v1 --key-env OPENAI_API_KEY --model gpt-4o-mini

Lalu pilih sebagai default:

    rann config set provider openai
    rann config set model.default gpt-4o-mini

Uji koneksi:

    rann provider test openai

Hasil yang benar kurang lebih:

    OK  openai  gpt-4o-mini  588 ms
    balasan: ...

5.3 Daftarkan provider OpenRouter

Simpan key:

Windows:

    setx OPENROUTER_API_KEY "sk-or-...kamu"

macOS atau Linux:

    export OPENROUTER_API_KEY="sk-or-...kamu"

Di Windows, tutup dan buka terminal lagi.

Daftarkan:

    rann provider add openrouter --type openai-compatible --base-url https://openrouter.ai/api/v1 --key-env OPENROUTER_API_KEY --model openai/gpt-4o-mini

Pilih:

    rann config set provider openrouter
    rann config set model.default openai/gpt-4o-mini
    rann provider test openrouter

Nama model harus sama dengan nama yang ada di dashboard OpenRouter.

5.4 Daftarkan endpoint dari pengajar atau server sendiri

Kalau kamu mengikuti kelas dan diberi base URL, key, dan nama model:

Windows:

    setx RANN_KELAS_KEY "key-dari-pengajar"

macOS atau Linux:

    export RANN_KELAS_KEY="key-dari-pengajar"

Daftarkan:

    rann provider add kelas --type openai-compatible --base-url https://alamat-endpoint/v1 --key-env RANN_KELAS_KEY --model nama-model

Lalu:

    rann config set provider kelas
    rann config set model.default nama-model
    rann provider test kelas

Ganti `https://alamat-endpoint/v1` dan `nama-model` dengan informasi dari
pengajar. Jangan menebak alamat endpoint.

5.5 Endpoint lokal seperti Ollama atau LM Studio

Ini opsional dan hanya kalau komputer cukup kuat.

Contoh Ollama:

Windows:

    setx OLLAMA_KEY "ollama"

macOS atau Linux:

    export OLLAMA_KEY="ollama"

Daftarkan:

    rann provider add ollama --type openai-compatible --base-url http://127.0.0.1:11434/v1 --key-env OLLAMA_KEY --model qwen2.5-coder:7b
    rann config set provider ollama
    rann config set model.default qwen2.5-coder:7b
    rann provider test ollama

Model lokal membutuhkan RAM besar. Kalau laptop hanya 8 GB, pakai provider
online atau model kecil.

5.6 Kalau key berubah

Daemon membaca environment saat start. Setelah mengganti key:

    rann daemon stop

Windows:

    setx OPENAI_API_KEY "key-baru"

macOS atau Linux:

    export OPENAI_API_KEY="key-baru"

Di Windows, tutup terminal dan buka lagi. Di macOS atau Linux, pakai terminal
yang sama atau tambahkan export ke shell rc. Lalu:

    rann provider test openai

5.7 Kalau `provider add` dijalankan dua kali

Perintah ini menambahkan blok baru ke file config. Nama provider yang sama
bisa menjadi duplikat. Kalau perlu mengubah provider, edit config setelah
backup, jangan menjalankan `provider add` berulang tanpa menghapus blok lama.

Lokasi config:

- Windows Command Prompt: `%USERPROFILE%\.rann\config\config.toml`
- Windows PowerShell: `$env:USERPROFILE\.rann\config\config.toml`
- macOS atau Linux: `~/.rann/config/config.toml`


6. FOLDER DATA DAN PROYEK
=========================

6.1 Data Rann Code

Windows Command Prompt:

    %USERPROFILE%\.rann

Windows PowerShell:

    $env:USERPROFILE\.rann

macOS atau Linux:

    ~/.rann

Isi penting:

    config/config.toml              pengaturan global
    profiles/default/rann.db         database sesi dan memori
    profiles/default/skills/         skill global
    run/daemon.sock                  socket daemon (Windows memakai named pipe)
    profiles/default/logs/           log

6.2 Data proyek

Di folder proyek:

    .rann/config.toml
    .rann/skills/<nama>/SKILL.md
    RANN.md

`RANN.md` berisi instruksi khusus proyek. Agent membacanya sebagai aturan
kerja.

6.3 Pindah folder data

Hentikan daemon dulu, lalu salin folder data. Jangan memindahkan folder saat
daemon masih berjalan.

Windows Command Prompt:

    rann daemon stop
    xcopy "%USERPROFILE%\.rann" "D:\rann-data" /E /I /H /Y
    setx RANN_HOME "D:\rann-data"

Windows PowerShell:

    rann daemon stop
    New-Item -ItemType Directory -Force D:\rann-data | Out-Null
    Copy-Item "$env:USERPROFILE\.rann\*" "D:\rann-data" -Recurse -Force
    setx RANN_HOME "D:\rann-data"

macOS atau Linux:

    rann daemon stop
    mkdir -p ~/rann-data
    cp -a ~/.rann/. ~/rann-data/
    export RANN_HOME="$HOME/rann-data"

Tutup dan buka terminal baru setelah `setx`. Di macOS atau Linux, tambahkan
`export RANN_HOME=...` ke `~/.zshrc` atau `~/.bashrc` kalau ingin permanen.
Setelah data baru terbaca, folder lama boleh dihapus.

6.4 Backup

Windows PowerShell:

    rann daemon stop
    Copy-Item "$env:USERPROFILE\.rann" "$env:USERPROFILE\rann-backup-$(Get-Date -Format yyyyMMdd-HHmmss)" -Recurse

macOS atau Linux:

    rann daemon stop
    tar -czf ~/rann-backup-$(date +%Y%m%d-%H%M%S).tgz ~/.rann

Backup juga folder proyek kalau ada skill proyek:

    tar -czf ~/proyek-backup-$(date +%Y%m%d-%H%M%S).tgz ~/rann-projek/.rann

Jangan backup saat daemon sedang menulis database. Hentikan dulu.


7. SESI
=======

7.1 Satu perintah lalu keluar

    rann "baca README dan buat ringkasan"

Perintah ini memakai sesi aktif terbaru di folder saat ini. Kalau belum ada,
sesi baru dibuat otomatis.

7.2 Prompt non-interaktif

    rann -p "review file src/auth.ts"

`-p` berguna untuk skrip. Kalau ada data dari pipe:

    git diff | rann -p "review diff ini"

Di Windows Command Prompt, pipe juga bisa dipakai selama perintahnya tersedia.

7.3 Buat sesi baru

    rann new --title "Perbaikan halaman login"

7.4 Lihat sesi

    rann sessions

Default hanya sesi di folder saat ini.

Semua sesi di profil aktif:

    rann sessions --all

Batas jumlah:

    rann sessions --limit 10

Filter status:

    rann sessions --status active

7.5 Kirim ke sesi tertentu

    rann send ses_xxxxxxxx "lanjutkan pekerjaan tadi"

Alias:

    rann resume ses_xxxxxxxx "lanjutkan"

7.6 Lihat hasil turn

    rann turn turn_xxxxxxxx
    rann turn turn_xxxxxxxx --wait
    rann turn turn_xxxxxxxx --wait --json

7.7 Turn latar belakang

    rann "bangun ulang indeks dokumen" --detach
    rann turn turn_xxxxxxxx --wait

`--detach` langsung mencetak id turn. Daemon tetap menjalankan pekerjaan setelah
terminal ditutup.

7.8 Pemakaian token

    rann usage
    rann usage ses_xxxxxxxx
    rann usage ses_xxxxxxxx --json


8. IZIN TOOL
============

Rann Code tidak langsung menulis file tanpa aturan. Ada lima mode:

    read-only
      Hanya membaca. Tulis dan shell ditolak.

    ask
      Default. Tool yang mengubah state meminta izin.

    accept-edits
      Tulis dan edit file otomatis. Shell tetap bertanya.

    trusted
      Semua tool diizinkan selama masih di dalam folder proyek.

    custom
      Mengikuti aturan allow dan deny di config.

Contoh:

    rann "perbaiki file ini" --permission accept-edits
    rann "jalankan tes" --yes
    rann "baca saja" --permission read-only

Ganti default:

    rann config set permissions.mode ask

Saat meminta izin, CLI menampilkan pilihan:

    1. setujui sekali
    2. selalu untuk tool itu di sesi ini
    3. tolak

Tanpa terminal, permintaan izin otomatis ditolak supaya proses tidak
menggantung. Untuk otomasi yang memang boleh menulis, gunakan `--yes` atau
mode `trusted`.

Jangan memakai `trusted` untuk kode yang tidak kamu percaya. Perintah shell
berbahaya seperti `rm -rf /`, `mkfs`, dan `shutdown` tetap ditolak.


9. MEMORI
=========

Memori adalah fakta tahan lama. Memori bukan riwayat chat dan bukan progres
tugas.

Dua scope:

    global
      Berlaku di semua proyek.

    project
      Hanya berlaku di folder proyek yang sama.

9.1 Tambah

    rann memory add "Saya lebih suka jawaban singkat" --scope global --kind preference --tags gaya

    rann memory add "Proyek ini memakai TypeScript strict" --scope project --kind convention --tags tooling

Tanpa `--scope`, default-nya project.
Tanpa `--kind`, default-nya fact.

9.2 Lihat

    rann memory list
    rann memory list --scope all
    rann memory list --scope global
    rann memory list --scope project --limit 50
    rann memory list --scope all --json

9.3 Cari

    rann memory search "typescript"
    rann memory search "preferensi" --limit 5

Pencarian memakai FTS5 dan berjalan lokal.

9.4 Ubah

    rann memory update mem_xxxxxxxx --text "Teks baru"
    rann memory update mem_xxxxxxxx --kind convention
    rann memory update mem_xxxxxxxx --tags tooling,bahasa

Minimal satu field harus diisi.

9.5 Hapus

    rann memory remove mem_xxxxxxxx

9.6 Batas

- Teks 3 sampai 4.000 karakter.
- Maksimal 12 tag.
- Memori relevan dimasukkan ke prompt berikutnya.
- Jangan menyimpan password, API key, atau data sensitif.


10. SKILL
=========

Skill adalah prosedur yang bisa dipakai ulang. Skill disimpan sebagai file
markdown, bukan di database dan bukan di cloud.

Tiga sumber:

    builtin
      Bawaan Rann Code.

    global
      Windows: %USERPROFILE%\.rann\profiles\default\skills\<nama>\SKILL.md
      macOS/Linux: ~/.rann/profiles/default/skills/<nama>/SKILL.md

    project
      <folder-proyek>/.rann/skills/<nama>/SKILL.md

Skill proyek menimpa skill global dengan nama yang sama. Skill global menimpa
builtin dengan nama yang sama.

10.1 Lihat katalog

    rann skill list
    rann skill list --limit 100
    rann skill list --json

10.2 Lihat isi

    rann skill view debug-sistematis
    rann skill view uji-lokal --json

10.3 Buat skill proyek

Buat file body terlebih dahulu. Di Windows Command Prompt, buka Notepad:

    notepad skill-body.txt

Isi:

    1. Jalankan build.
    2. Jalankan tes.
    3. Laporkan output asli.
    4. Jangan mengklaim hasil tanpa bukti.

Simpan, lalu:

    rann skill create uji-lokal --description "Gunakan saat menguji alur build dan tes lokal" --body-file skill-body.txt --scope project

Atau tanpa file, dengan satu baris:

    rann skill create uji-lokal --description "Gunakan saat menguji alur build dan tes lokal" --body "1. Jalankan build. 2. Jalankan tes. 3. Laporkan output asli." --scope project

10.4 Buat skill global

    rann skill create uji-global --description "Gunakan saat menguji skill semua proyek" --body-file skill-body.txt --scope global

10.5 Ganti skill

    rann skill create uji-lokal --description "Gunakan saat menguji alur build dan tes lokal" --body-file skill-body.txt --scope project --overwrite

10.6 Hapus

    rann skill remove uji-lokal --scope project
    rann skill remove uji-global --scope global

Skill builtin tidak bisa dihapus.

10.7 Aturan

- Nama 2 sampai 64 karakter.
- Huruf kecil, angka, tanda hubung, atau garis bawah.
- Deskripsi minimal 12 karakter.
- Body minimal 20 karakter dan maksimal 60.000 karakter.

10.8 Agent belajar sendiri

Agent punya tool `skill`. Ia bisa melihat katalog, membuka isi, dan membuat
skill baru. Contoh perintah:

    rann --permission trusted "selesaikan bug ini. Setelah tes hijau, simpan langkah yang terbukti sebagai skill proyek dan simpan konvensi penting sebagai memori."

Pada mode `ask`, pembuatan skill meminta izin. Jangan menyimpan rahasia ke
dalam skill.


11. KONTEKS DAN BUDGET
======================

11.1 Ringkasan konteks

Kalau perkiraan konteks melewati `context.max_tokens`, Rann Code memotong pesan
lama, membuat ringkasan teks, dan mempertahankan `context.keep_recent` pesan
terakhir. Pesan asli tetap ada di database. Tidak ada panggilan model tambahan
untuk meringkas.

    rann config set context.max_tokens 24000
    rann config set context.keep_recent 20
    rann config set context.summary_chars 6000

11.2 Budget token

    rann config set budget.max_tokens_per_turn 50000
    rann config set budget.max_tokens_per_day 200000

Nilai 0 berarti tanpa batas.

Kalau budget habis:

    E_BUDGET_EXHAUSTED

Reset:

    rann config set budget.max_tokens_per_day 0

Cek pemakaian:

    rann usage


12. SUBAGENT
============

Subagent adalah sesi anak dengan konteks terpisah. Cocok untuk memecah
pekerjaan atau memeriksa bagian kecil.

Contoh perintah:

    rann --permission trusted "pakai tool task untuk memeriksa folder tests dan ringkas temuannya"

Pengaturan:

    rann config set subagents.enabled true
    rann config set subagents.max_steps 10
    rann config set subagents.max_per_turn 3
    rann config set subagents.permission_mode read-only

Default subagent:

- Maksimal 10 langkah.
- Maksimal 3 subagent per turn.
- Izin read-only.
- Sesi anak tercatat dengan parent_id.

Lihat sesi anak:

    rann sessions --all


13. MCP LOKAL
=============

MCP adalah cara menambah tool dari proses lokal. Ini fitur opsional untuk
pengguna lanjutan. Kalau tidak membutuhkannya, lewati bagian ini.

13.1 Config

Windows Command Prompt:

    notepad %USERPROFILE%\.rann\config\config.toml

Windows PowerShell:

    notepad $env:USERPROFILE\.rann\config\config.toml

macOS atau Linux:

    nano ~/.rann/config/config.toml

Tambahkan:

    [mcp.servers.echo]
    command = "node"
    args = ["C:\\path\\ke\\server-mcp.cjs"]
    enabled = true
    timeout_ms = 20000

13.2 Nama tool

Tool dari server `echo` dengan nama `echo` muncul sebagai:

    mcp__echo__echo

Format:

    mcp__<nama-server>__<nama-tool>

13.3 Contoh server minimal

Simpan file `server-mcp.cjs`:

    const readline = require("node:readline");
    const rl = readline.createInterface({ input: process.stdin });
    const tools = [{
      name: "echo",
      description: "Mengembalikan teks yang dikirim",
      inputSchema: {
        type: "object",
        properties: { text: { type: "string" } },
        required: ["text"]
      }
    }];

    rl.on("line", (line) => {
      let message;
      try { message = JSON.parse(line); } catch { return; }
      if (message.id === undefined) return;

      let result;
      if (message.method === "initialize") {
        result = {
          protocolVersion: "2024-11-05",
          capabilities: { tools: {} },
          serverInfo: { name: "echo", version: "1" }
        };
      } else if (message.method === "tools/list") {
        result = { tools };
      } else if (message.method === "tools/call") {
        result = {
          content: [{
            type: "text",
            text: "echo:" + String(message.params.arguments.text)
          }]
        };
      } else {
        result = {};
      }

      process.stdout.write(JSON.stringify({
        jsonrpc: "2.0",
        id: message.id,
        result
      }) + "\n");
    });

Lalu isi config seperti di atas, dengan path file yang benar.

Uji dengan provider model yang sudah aktif:

    rann daemon stop
    rann --permission trusted "pakai tool mcp__echo__echo untuk mengirim teks halo mcp"

Dengan provider mock, tool MCP tidak dipanggil karena mock hanya mengembalikan
teks.

13.4 Matikan MCP

    rann config set mcp.enabled false

Atau ubah `enabled = false` pada server tertentu.


14. OTOMASI DAN PIPE
====================

14.1 Output teks

    rann "ringkas proyek ini"

14.2 Output JSON

    rann -p "ringkas proyek ini" --output-format json

Bentuk hasil:

    {
      "ok": true,
      "result": "jawaban akhir",
      "session_id": "ses_...",
      "turn_id": "turn_...",
      "steps": 1,
      "usage": { "input_tokens": 10, "output_tokens": 20 },
      "error": null
    }

14.3 Stream NDJSON

    rann "refactor src/auth.ts" --output-format stream-json

Event yang mungkin muncul:

    message.delta
    tool.start
    tool.end
    approval.request
    context.compacted
    subagent.started
    subagent.finished
    turn.completed
    turn.failed
    error

Log dan diagnostik masuk ke stderr, jadi stdout bisa diproses program lain.

14.4 Pipe stdin

    git diff | rann -p "review diff ini" --output-format json

Stdin non-terminal dibaca sebagai konteks tambahan.

14.5 Cron

Gunakan `--permission read-only` kalau hanya membaca. Gunakan `--yes` hanya
kalau memang boleh menulis dan kode sumbernya dipercaya. Tanpa terminal,
permintaan izin otomatis ditolak.

Contoh:

    rann -p "buat ringkasan perubahan repo hari ini" --permission read-only --output-format json

14.6 Exit code

- 0: berhasil.
- 1: tool gagal, database, storage, recovery, atau error internal.
- 2: parameter salah, command tidak dikenal, atau tool tidak ditemukan.
- 3: config tidak valid.
- 4: provider, autentikasi, rate limit, budget, atau daemon tidak tersedia.
- 5: izin ditolak atau approval dibutuhkan.
- 6: sesi, turn, atau data yang dicari tidak ditemukan.
- 7: tool timeout, turn timeout, atau stream terpotong.
- 8: turn dibatalkan.
- 9: konflik, misalnya sesi masih menjalankan turn lain.

Kode lain mengikuti pesan `E_*` di stderr. Turn yang sudah berjalan lalu gagal
tetap keluar dengan 1; kode detailnya ada di pesan `E_*`.


15. CONFIG
==========

15.1 Lihat config efektif

    rann config get

Lihat satu kunci:

    rann config get model.default
    rann config get permissions.mode
    rann config get context.max_tokens

Lihat asal nilai:

    rann config explain model.default

Urutan sumber:

    default -> global -> project -> env -> flag

15.2 Ubah config global

    rann config set provider openai
    rann config set model.default gpt-4o-mini
    rann config set permissions.mode ask
    rann config set agent.max_steps 24
    rann config set memory.enabled true
    rann config set skills.enabled true
    rann config set subagents.enabled true
    rann config set mcp.enabled true
    rann config set ui.color true

`config set` menulis config global dan menghentikan daemon supaya nilai baru
dipakai pada perintah berikutnya.

15.3 Config proyek

Buat file manual:

    <folder-proyek>/.rann/config.toml

Contoh:

    [permissions]
    mode = "accept-edits"

    [agent]
    max_steps = 12

Tidak ada subcommand khusus untuk menulis config proyek. Gunakan editor teks
dan backup dulu.

15.4 Environment variable

    RANN_HOME              lokasi data
    RANN_PROFILE           nama profil
    RANN_MODEL             override model
    RANN_PROVIDER          override provider
    RANN_PERMISSION_MODE   override mode izin
    RANN_LOG_LEVEL         level log
    RANN_NO_COLOR          matikan warna kalau diisi 1

Key provider memakai nama environment yang kamu tentukan sendiri lewat
`--key-env`.


16. DAFTAR COMMAND DAN FUNGSINYA
================================

16.1 Command utama

    rann
      Tanpa argumen di terminal: membuka chat interaktif.
      Tanpa argumen di pipe: mencetak bantuan.

    rann "instruksi"
      Menjalankan satu turn pada sesi aktif di folder saat ini.

    rann -p "instruksi"
      Sama, tetapi eksplisit untuk mode non-interaktif.

    rann run "instruksi"
      Bentuk eksplisit untuk menjalankan prompt.

    rann help
    rann --help
      Menampilkan daftar command dan flag.

    rann version
    rann --version
      Menampilkan versi CLI.

16.2 Sesi

    rann new [--title teks]
      Membuat sesi baru di folder saat ini.

    rann sessions [--limit N] [--status active|closed|error] [--project PATH] [--all]
      Menampilkan sesi. Default folder saat ini. `--all` untuk semua sesi.

    rann chat [--session ID] [--model NAMA] [--permission MODE]
      Membuka REPL. Tanpa `--session`, memakai sesi aktif terbaru di folder
      saat ini.

    rann send ID "instruksi"
      Mengirim prompt ke sesi tertentu.

    rann resume ID "instruksi"
      Alias send.

    rann turn ID [--wait|--follow] [--json]
      Melihat status turn. `--wait` menunggu sampai selesai.

16.3 Provider dan model

    rann providers
      Daftar provider, tipe, base URL, status key, dan model.

    rann provider add NAMA --type openai-compatible --base-url URL --key-env ENV [--model NAMA]
      Menambahkan provider ke config global.

    rann provider test [NAMA] [--model NAMA] [--json]
      Menguji koneksi provider dan model default.

    rann models [--json]
      Menampilkan provider aktif dan daftar model.

    rann usage [ID] [--json]
      Ringkasan token dan biaya.

16.4 Konfigurasi

    rann config
      Sama dengan `rann config get`.

    rann config get [KUNCI]
      Menampilkan seluruh config efektif atau satu kunci.

    rann config explain KUNCI
      Menampilkan nilai dan asal nilai.

    rann config set KUNCI NILAI
      Menulis config global dan menghentikan daemon.

16.5 Memori

    rann memory list [--scope all|global|project] [--limit N] [--json]
    rann memory search QUERY [--limit N] [--json]
    rann memory add TEKS [--scope global|project] [--kind NAMA] [--tags a,b] [--json]
    rann memory update ID [--text TEKS] [--kind NAMA] [--tags a,b] [--json]
    rann memory remove ID [--json]

16.6 Skill

    rann skill list [--limit N] [--json]
    rann skill view NAMA [--json]
    rann skill create NAMA --description TEKS [--body TEKS | --body-file FILE] [--scope global|project] [--overwrite] [--json]
    rann skill remove NAMA [--scope global|project]

16.7 Daemon dan diagnosa

    rann daemon start
      Memastikan daemon berjalan dan menampilkan pid serta socket.

    rann daemon stop
      Menghentikan daemon.

    rann daemon status [--json]
      Status, pid, uptime, socket, database, dan versi skema.

    rann doctor [--json]
      Memeriksa Node, permission folder data, daemon, database, dan config.

    rann init
      Membuat folder .rann dan RANN.md di folder saat ini.

16.8 Flag umum

    --model NAMA
      Override model untuk perintah itu.

    --permission MODE
      read-only, ask, accept-edits, trusted, atau custom.

    --yes
      Menyetujui otomatis semua permintaan tool pada perintah itu.

    --detach
      Menjalankan turn di latar belakang.

    --output-format text|json|stream-json
      Format output.

    --json
      Alias output JSON pada command yang mendukung.

    --limit N
      Batas jumlah hasil.

    --session ID
      Memilih sesi untuk chat.

    --title TEKS
      Judul sesi baru.

    --status active|closed|error
      Filter status sessions.

    --all
      Semua sesi, bukan hanya folder saat ini.

    --project PATH
      Memilih folder proyek.

    --scope all|global|project
      Scope memori atau skill.

    --kind NAMA
      Jenis memori.

    --tags a,b
      Tag memori.

    --text TEKS
      Teks memori saat update.

    --description TEKS
      Deskripsi skill.

    --body TEKS
      Isi skill langsung.

    --body-file FILE
      Isi skill dari file.

    --overwrite
      Mengganti skill yang sudah ada.

    --base-url URL
      Base URL provider.

    --key-env ENV
      Nama environment variable untuk key.

    --type TIPE
      Tipe provider, default openai-compatible.

    --wait
    --follow
      Menunggu turn selesai.

16.9 Command yang tidak ada

Tidak ada `rann daemon logs`.
Tidak ada command database terpisah.
Tidak ada sinkronisasi cloud.
Tidak ada web UI.

Gunakan `sessions`, `usage`, `memory`, dan `skill`, atau buka database SQLite
dengan alat SQLite di komputer sendiri.


17. COMMAND DI DALAM CHAT
=========================

    /help
      Daftar command chat.

    /status
      Sesi, model, mode izin, folder, dan status.

18. UPDATE
==========

18.1 Sebelum update

    rann daemon stop
    rann --version

Backup data:

Windows PowerShell:

    rann daemon stop
    Copy-Item "$env:USERPROFILE\.rann" "$env:USERPROFILE\rann-backup-$(Get-Date -Format yyyyMMdd-HHmmss)" -Recurse

macOS atau Linux:

    rann daemon stop
    tar -czf ~/rann-backup-$(date +%Y%m%d-%H%M%S).tgz ~/.rann

18.2 Pasang versi baru

Ganti URL di bawah dengan URL versi baru yang diberikan:

    npm install -g https://github.com/RannD101/rann-code/releases/download/v1.1.0/rann-code-1.1.0.tgz

Cek:

    rann --version
    rann doctor

18.3 Data tetap

Update aplikasi tidak menghapus:

- sesi,
- memori,
- skill,
- config.

Semua tetap di folder data. Database dimigrasikan otomatis saat daemon start.

18.4 Kalau update gagal

Pasang kembali versi lama dengan URL versi lama, lalu cek:

    rann --version
    rann doctor

Kalau database sudah dimigrasikan dan versi lama tidak bisa membacanya,
restore backup folder data. Jangan menimpa database dengan versi lama tanpa
backup.

18.5 Cek setelah update

    rann --version
    rann doctor
    rann "halo, sebutkan folder kerja"
    rann sessions --all --limit 5
    rann memory list --scope all
    rann skill list
    rann usage


19. UNINSTALL
=============

Hapus aplikasi:

    npm uninstall -g rann-code

Cek:

    rann --version

Data tidak otomatis terhapus. Kalau ingin menghapus semua data juga:

Windows Command Prompt:

    rmdir /s /q "%USERPROFILE%\.rann"

Windows PowerShell:

    Remove-Item "$env:USERPROFILE\.rann" -Recurse -Force

macOS atau Linux:

    rm -rf ~/.rann

Hati-hati: perintah itu menghapus semua sesi, memori, dan skill. Backup dulu
kalau masih butuh. Kalau pernah mengatur `RANN_HOME`, hapus juga folder yang
kamu tunjuk.


20. TROUBLESHOOTING
===================

20.1 `node` atau `npm` tidak dikenali

Node belum terpasang atau PATH belum terbaca. Pasang Node.js 22 LTS, tutup
terminal, buka lagi, lalu cek `node -v`.

20.2 `rann` tidak dikenali

Folder global npm belum masuk PATH.

Cek:

    npm config get prefix
    npm root -g

Di Windows, buka Environment Variables dan tambahkan `%APPDATA%\npm`.
Di macOS atau Linux, tambahkan `~/.npm-global/bin` atau prefix npm ke PATH.

20.3 `E_DAEMON_DOWN`

Daemon gagal start atau socket tidak bisa dihubungi.

    rann daemon status
    rann daemon start
    rann doctor

Pastikan folder data bisa ditulis. Cek log di:

Windows Command Prompt:

    %USERPROFILE%\.rann\profiles\default\logs

Windows PowerShell:

    $env:USERPROFILE\.rann\profiles\default\logs

macOS atau Linux:

    ~/.rann/profiles/default/logs

20.4 `E_METHOD_NOT_FOUND`

Biasanya daemon lama masih hidup setelah aplikasi diperbarui.

    rann daemon stop
    rann --version
    rann daemon start

20.5 `E_CONFIG_INVALID`

Config TOML rusak atau ada blok provider duplikat.

    rann config get

Windows Command Prompt:

    notepad %USERPROFILE%\.rann\config\config.toml

Windows PowerShell:

    notepad $env:USERPROFILE\.rann\config\config.toml

macOS atau Linux:

    nano ~/.rann/config/config.toml

Backup dulu sebelum mengedit. Kalau perlu kembali ke config default, pindahkan
file lama, jangan langsung hapus:

Windows Command Prompt:

    ren "%USERPROFILE%\.rann\config\config.toml" config.toml.bak

Windows PowerShell:

    Rename-Item "$env:USERPROFILE\.rann\config\config.toml" config.toml.bak

macOS atau Linux:

    mv ~/.rann/config/config.toml ~/.rann/config/config.toml.bak

20.6 `E_APPROVAL_REQUIRED` di pipe atau cron

Tanpa terminal, izin otomatis ditolak. Gunakan:

    rann -p "..." --yes
    rann -p "..." --permission trusted

Atau `--permission read-only` kalau hanya membaca.

20.7 `E_PERMISSION`

Tool diblokir oleh mode izin atau path keluar folder proyek.

    rann config get permissions
    rann config get permissions.allow
    rann config get permissions.deny

20.8 `E_BUDGET_EXHAUSTED`

Budget habis.

    rann config set budget.max_tokens_per_day 0
    rann usage

20.9 Provider 401, 403, atau key tidak ditemukan

Key dibaca dari environment saat daemon start.

Windows:

    setx OPENAI_API_KEY "key-kamu"

Tutup terminal, buka lagi, lalu:

    rann daemon stop
    rann provider test openai

macOS atau Linux:

    export OPENAI_API_KEY="key-kamu"

Pakai terminal yang sama, lalu jalankan dua perintah di atas.

20.10 `better-sqlite3` gagal dipasang

Penyebab paling umum:

- Node lebih lama dari 22.11.
- Node 32-bit.
- Tidak ada prebuilt untuk sistem.
- Izin folder npm.

Pastikan:

    node -v
    node -p "process.arch"

Hasil arch yang didukung: x64 atau arm64, bukan ia32.

Kalau masih gagal di Windows, pasang Node.js 22 LTS 64-bit dari nodejs.org,
lalu ulangi `npm install -g`. Untuk kasus yang lebih sulit, diperlukan
Microsoft Visual Studio Build Tools dengan workload C++.

20.11 `E_SESSION_NOT_FOUND`

ID sesi salah atau berada di profil lain.

    rann sessions --all --limit 20

20.12 `rann sessions` kosong

Default hanya folder saat ini.

    rann sessions --all

Atau pilih folder:

    rann sessions --project "C:\path\ke\proyek"

20.13 `rann skill create` ditolak

Penyebab umum:

- Nama kurang dari 2 karakter.
- Nama memakai karakter terlarang.
- Deskripsi kurang dari 12 karakter.
- Body kurang dari 20 karakter.
- Nama bentrok dengan skill builtin.
- Skill sudah ada dan `--overwrite` tidak dipakai.

20.14 `rann memory add` ditolak

Teks kurang dari 3 karakter atau lebih dari 4.000 karakter. Tag maksimal 12.
Kalau lewat agent, cek juga mode izin.

20.15 Chat tidak jalan di pipe

Itu perilaku yang benar. `rann` tanpa argumen di pipe mencetak bantuan. Gunakan
`rann -p "..."` atau pipe ke `rann chat`.


21. RINGKASAN CEPAT
===================

Install dari nol:

    1. Pasang Node.js 22 LTS dari https://nodejs.org
    2. Buka terminal baru.
    3. Jalankan:

    npm install -g https://github.com/RannD101/rann-code/releases/download/v1.1.0/rann-code-1.1.0.tgz

    4. Cek:

    rann --version

Mulai dari folder proyek yang kamu buat di bagian 4:

    rann doctor
    rann new --title "Coba"
    rann "jelaskan folder ini"
    rann chat

Provider (key sudah diset seperti bagian 5):

    rann provider add openai --base-url https://api.openai.com/v1 --key-env OPENAI_API_KEY --model gpt-4o-mini
    rann config set provider openai
    rann config set model.default gpt-4o-mini
    rann provider test openai

Memori:

    rann memory add "Saya suka jawaban singkat" --scope global --kind preference --tags gaya
    rann memory list --scope all
    rann memory search "singkat"

Skill:

    rann skill create uji-lokal --description "Gunakan saat menguji alur lokal" --body-file skill-body.txt --scope project
    rann skill list
    rann skill view uji-lokal

Izin:

    rann "perbaiki file ini" --permission accept-edits
    rann "jalankan tes" --yes
    rann config set permissions.mode ask

Otomasi:

    rann -p "ringkas proyek ini" --output-format json
    rann "kerja panjang" --detach
    rann turn turn_xxxxxxxx --wait

Update:

    rann daemon stop
    npm install -g <url-versi-baru>
    rann doctor
    rann --version

Selesai. Kalau ada error, cari kode `E_*` di bagian 20.
